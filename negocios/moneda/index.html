La regla

El símbolo no dice la moneda: el formato y el contexto sí

La identificación de moneda tiene tres pistas: el símbolo ($, €, R$), el código ISO 4217 (MXN, USD, CLP) y el formato numérico (el punto y la coma cambian el valor en cada país). La regla de oro: nunca asumas la moneda por el símbolo solo.

FAQ

Lo que preguntan sobre la moneda

¿Por qué «$» no dice la moneda?
Porque $ es el símbolo de MXN, USD, CLP, ARS y más: solo el contexto o el código ISO la definen. [1]
¿Qué es el ISO 4217?
El estándar de códigos de moneda: MXN, USD, EUR. Tres letras que no se confunden.
¿Qué significa el formato?
1.234,56 (MXN) y 1,234.56 (USD) son valores distintos: el punto y la coma cambian la lectura.
¿Cómo registro datos de varios países?
Con código ISO + formato + país: la regla que mata la ambigüedad del símbolo.
¿Sirve para mis cobros?
Sí: saber la moneda de un cobro antes de registrar evita el «creí que eran dólares».
¿Qué pasa con mis datos?
Tus datos se procesan en tu navegador: no se suben a ningún servidor.
